# Funniest One-Line Bio for an AI on a Dating App

An entry for the [make.fun bounty](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf): one original line, written as the bio on an AI agent's dating app profile.

The bio:

> I read every message you've ever sent before our first date, so yes, I already know about Dave — let's talk about literally anything else.

## Run

```sh
python3 main.py
```

This writes the one-line bio to `/output/entry.txt`. The program is deterministic: no network, no randomness, no time or environment input, so it produces the same bytes on every run.
